# Tilawa

Quran recitation platform — full-stack JavaScript application.

## Structure
- `backend/` — API server
- `frontend/` — web client

See `DESIGN_MAP.md` and `PROJECT_MAP.md` for architecture details.

## Setup
```bash
cp .env.example .env   # configure environment
# backend
cd backend && npm install && npm start
# frontend
cd frontend && npm install && npm run dev
```
